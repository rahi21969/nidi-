# For Nidi, with love

A small, responsive romantic surprise website for Nidi. It's a static site: open `index.html` in a browser to preview it.

## Personalize it later

- Replace the text in `index.html` with your own memories and words.
- Add photos when you're ready (the layout can be updated with a photo gallery).
- The site uses Google Fonts when online and includes Georgia fallbacks.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish `index.html`.
